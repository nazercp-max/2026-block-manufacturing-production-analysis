# 🏭 2026 Block Manufacturing Production Analysis

### Production Data Analysis & Dashboard Project

**Author:** Abdul Nazer Chakkiparamban

## 📌 Project Overview

This project analyzes block manufacturing production data for 2026 to understand production trends, production-day patterns, product contribution, and operational performance.

The analysis was developed using **Microsoft Excel**, with PivotTables, PivotCharts, formulas, and interactive dashboards. A cleaned portfolio version was also prepared and published as a Kaggle notebook.

## 🎯 Project Objectives

The main objectives of this analysis are to:

- Monitor monthly production trends.
- Compare production performance across production days.
- Identify production patterns by day of the week.
- Analyze product-wise production contribution.
- Track production days and zero-production days.
- Calculate average production per production day.
- Present key performance indicators through dashboards.

## 🔍 Key Findings

The analysis identified several important production patterns:

- Production varied significantly from month to month.
- CHB 8-inch blocks represented the largest share of total production during the analyzed period.
- Production activity varied across days of the week.
- Some days had zero production due to scheduled non-production days and operational conditions.
- Monitoring production-day averages provides a better understanding of daily manufacturing performance.

## 📈 Dashboard Analysis

The dashboards provide a visual summary of production performance, including:

- Total production
- Monthly production trends
- Production-day performance
- Zero-production days
- Product contribution
- Day-of-week production patterns
- Key production indicators

## 💡 Recommendations

Based on the analysis:

1. Monitor monthly production trends regularly to identify significant increases or decreases.
2. Focus on production planning using historical production-day patterns.
3. Monitor product contribution to understand demand and production priorities.
4. Review zero-production days and identify opportunities to improve production availability.
5. Use dashboard KPIs for regular production monitoring and decision-making.
